# تشغيل الروبوت على سيرفر Windows (VPS)

الروبوت لازم يشتغل على جهاز **Windows** يظل شغال طول أيام التداول، وعليه برنامج **MT5 للكمبيوتر**.
وأنت تتابع كل شي من تطبيق MT5 في جوالك، لأنه نفس الحساب، ومن رسائل تيليجرام.

> ابدأ دائماً على **حساب ديمو**. الروبوت يرفض الحساب الحقيقي إلا إذا فعّلته أنت بنفسك.

## 1. السيرفر
- اسأل الوسيط حقك: "هل عندكم VPS مجاني؟" كثير منهم يعطونه مجاناً إذا رصيدك فوق حد معين.
- أو استأجر **Windows VPS**: يكفي 2GB رام، وتقريباً 10$ إلى 20$ بالشهر.
- تدخل على السيرفر من جوالك أو من أي كمبيوتر بتطبيق **Microsoft Remote Desktop**.

## 2. برنامج MT5 للكمبيوتر
1. نزّل MT5 من موقع الوسيط، وسجّل دخول بحساب **الديمو**.
2. من Tools ← Options ← Expert Advisors فعّل **Allow algorithmic trading**.
3. اضغط زر **Algo Trading** في شريط الأدوات لين يصير أخضر.
4. خل MT5 يفتح تلقائياً مع تشغيل الجهاز: حط اختصار له في مجلد `shell:startup`.

## 3. بايثون والملفات
1. نزّل **Python 3.12** من python.org، ووقت التثبيت علّم على **Add python.exe to PATH**.
2. افتح موجه الأوامر (cmd) واكتب:
   ```
   pip install MetaTrader5
   ```
3. نزّل مستودع Tadawal. إما بأمر `git clone`، أو من GitHub تضغط Code ← Download ZIP وتفك الضغط مثلاً في `C:\Tadawal`.

## 4. الإعدادات
افتح cmd داخل `C:\Tadawal` ونفّذ:
```
mkdir trader
copy config.example.json trader\config.json
notepad trader\config.json
```
وعدّل في الملف:
- `"mode": "mt5"`
- `"account_balance"`: رصيد حسابك.
- `"symbol_suffix"`: إذا الوسيط يكتب الزوج مثل `EURUSDm` حط `"m"`، وإذا يكتبه `EURUSD` عادي خله فاضي `""`.
- `"no_overnight": true`، وهذا مضبوط من البداية.

بعدها تأكد إن الربط شغال:
```
python skills\order-executor\order.py account
```
لازم يطلع لك رقم حسابك وكلمة **demo**.

## 5. تجهيز الروبوت واختباره
```
python skills\auto-trader\robot.py setup --pairs EURUSD XAUUSD --strategy trend_pullback --tf M15 --risk 0.5
python skills\auto-trader\robot.py backtest --days 60
python skills\auto-trader\robot.py once --dry-run
```
- `backtest`: يختبر الاستراتيجية على بيانات قديمة. إذا النتيجة ضعيفة، **لا تشغّله**. خل Claude يجرب معك استراتيجية أو فريم ثاني.
- `once --dry-run`: يمشي دورة وحدة ويوريك وش كان بيسوي، بدون ما يفتح أي صفقة.

## 6. تيليجرام (رسائل وتحكم من الجوال)
1. في تيليجرام افتح **@BotFather**، واكتب `/newbot`، وانسخ الـ token اللي يعطيك.
2. على السيرفر في cmd اكتب الأمر هذا، وبعده سكّر cmd وافتحه من جديد:
   ```
   setx TELEGRAM_BOT_TOKEN "حط-التوكن-هنا"
   ```
3. أرسل أي رسالة لبوتك، وبعدين نفّذ:
   ```
   python skills\auto-trader\robot.py telegram-chats
   python skills\auto-trader\robot.py set telegram_chat_id الرقم-اللي-طلع-لك
   python skills\auto-trader\robot.py telegram-test
   ```

الأوامر اللي تقدر ترسلها لبوتك من الجوال:

| الأمر | وش يسوي |
|---|---|
| `/status` أو `الحالة` | حالة الروبوت وصفقات اليوم |
| `/stop` أو `وقف` | يوقف الصفقات الجديدة. الصفقات المفتوحة تكمل بستوبها |
| `/start` أو `تشغيل` | يرجّع الروبوت يشتغل |
| `/flat` أو `سكر الكل` | يسكر كل الصفقات ويوقف الروبوت |

## 7. التشغيل
- شغّل الملف `tools\windows\start_robot.bat` بضغطتين. يشغّل الروبوت، وإذا وقف يرجّع يشغله تلقائياً.
- عشان يشتغل لحاله كل ما السيرفر يعيد التشغيل: افتح **Task Scheduler** ← Create Basic Task ← اختر **When I log on** ← وحدد ملف `start_robot.bat`.
- لا تسجّل خروج من السيرفر (Sign out). سكّر نافذة Remote Desktop بس، والروبوت يكمل شغله.

## 8. وش يسوي الروبوت كل يوم (بتوقيت الرياض في الشتاء)

| الوقت | وش يصير |
|---|---|
| 11 الصبح إلى 12 بالليل | يدخل صفقات وقت جلسة لندن ونيويورك بس، ولما تتحقق شروط الاستراتيجية |
| قبل الأخبار القوية بـ 30 دقيقة، وبعدها بـ 15 دقيقة | ما يدخل صفقات جديدة |
| 12:00 بالليل | آخر وقت لصفقة جديدة |
| 12:45 بالليل | يسكر كل الصفقات ويلغي الأوامر المعلقة. **ما فيه تبييت** |
| بعد خسارتين في اليوم | يوقف لين اليوم الجاي |

في الصيف كل هذي المواعيد تصير قبلها بساعة، والروبوت يحسبها تلقائياً.

## 9. ربط Claude بالسيرفر
عشان Claude يقدر يشوف الروبوت ويعدّل عليه، لازم يشتغل **على السيرفر نفسه**:
1. ثبّت **Claude Code** على السيرفر.
2. افتح cmd داخل `C:\Tadawal` واكتب:
   ```
   claude remote-control
   ```
3. الجلسة بتطلع لك في تطبيق Claude على جوالك (قسم Claude Code). من هناك تكلمه وكأنك على السيرفر.

## 10. المراجعة
كل يوم قبل جلسة لندن، اطلب من Claude: **"راجع الروبوت وحدد اتجاه اليوم"**.
وكل أسبوع اطلب: **"راجع صفقات الروبوت"**، وClaude يستخدم مهارة trade-coach.
وبعد 4 أسابيع على الأقل على الديمو، **أنت** تقرر إذا تنقله للحساب الحقيقي.
