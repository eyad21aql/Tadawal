# Tadawal — حزمة مهارات فوركس لـ Claude

15 مهارة لـ Claude لتداول **أزواج العملات والذهب** (EURUSD وGBPJPY وUSDJPY وXAUUSD…)
مع **ميتاتريدر 5**، سواء من الجوال أو من الكمبيوتر.
ما يتنفذ أي أمر إلا بعد فحص المخاطر وموافقتك الصريحة.

| # | المهارة | الأمر | وش تسوي |
|---|---|---|---|
| 1 | Entry Timer — مؤقّت الدخول | `entry-timer` | هل الحين وقت دخول شراء أو بيع؟ الاتجاه على فريمين، المؤشرات، الدعم والمقاومة، الجلسة الحالية، وتحذير لو فيه خبر قوي قريب |
| 2 | News Monitor — مراقب الأخبار | `news-monitor` | أخبار الأزواج اللي تتداولها، وبيانات البنوك المركزية (الفيدرالي والأوروبي والإنجليزي) |
| 3 | Chart Scanner — ماسح الشارت | `chart-scanner` | نماذج الشموع والقمة/القاع المزدوج والرأس والكتفين والمثلثات والاختراقات، ويقرأ صور الشارت اللي ترسلها |
| 4 | Risk Manager — مدير المخاطر | `risk-manager` | حجم اللوت من الستوب بالنقاط، وقيمة النقطة لكل زوج، وفحص يقبل أو يرفض كل أمر |
| 5 | Time Machine — آلة الزمن | `time-machine` | اختبار رجعي بالنقاط واللوتات مع حساب السبريد |
| 6 | Exit Planner — مخطط الخروج | `exit-planner` | الستوب والهدف بالنقاط، وجني الأرباح على مراحل، والوقف المتحرك |
| 7 | Price Alerts — تنبيهات الأسعار | `price-alerts` | تنبيه عند سعر معين، أو نسبة حركة، أو افتتاح جلسة (لندن ونيويورك وطوكيو) |
| 8 | Order Executor — منفّذ الأوامر | `order-executor` | يجهز لك الأمر خطوة بخطوة لتطبيق الجوال، أو يرسله لـ MT5 على الكمبيوتر، أو يحاكيه على حساب تجريبي |
| 9 | Budget Manager — مدير الميزانية | `budget-manager` | خطة الحساب، وجدول اللوتات، وسجل الصفقات، وتقرير الأداء |
| 10 | COT Tracker — متتبع الحيتان | `cot-tracker` | مراكز كبار المضاربين في كل عملة وفي الذهب، من تقرير COT الرسمي الأسبوعي |
| 11 | Economic Analyst — المحلل الاقتصادي | `economic-analyst` | الأجندة الاقتصادية بتوقيتك، والنتائج مقارنة بالتوقعات، والاتجاه الأساسي للزوج |
| 12 | Trading Plan — خطة التداول | `trading-plan` | تكتب قواعدك مرة وحدة (الأزواج والجلسات والنماذج والحدود وقائمة الفحص)، وكل صفقة تنفحص عليها قبل التنفيذ |
| 13 | Currency Strength — قوة العملات | `currency-strength` | ترتيب العملات الثمان من الأقوى للأضعف من 28 زوج، وأفضل زوج (قوية ضد ضعيفة)، وجدول الارتباط بين الأزواج |
| 14 | Market Structure — هيكل السوق (SMC) | `market-structure` | BOS وCHoCH والأوردر بلوك والفجوات السعرية (FVG) والسيولة وسحبها ومناطق الخصم والعلاوة، وصفقة SMC جاهزة |
| 15 | Trade Coach — مدرب التداول | `trade-coach` | يراجع صفقاتك ويقول لك وش تكمل عليه ووش تصلحه: انتقام من السوق، تكبير اللوت بعد الخسارة، كثرة الصفقات، تقفيل الربح بدري |

## ثلاث طرق للتنفيذ (`mode` في الإعدادات)

| الطريقة | لمين | كيف تشتغل |
|---|---|---|
| `manual` | **اللي يتداول من الجوال** | Claude يحلل ويحسب اللوت ويعطيك الأمر جاهز مع خطوات التطبيق. أنت تنفذه بيدك، وبعدها تعطيه سعر الدخول أو صورة الصفقة عشان يسجلها |
| `paper` | للتجربة | حساب تجريبي داخلي بدون أي وسيط |
| `mt5` | من عنده Windows | يرسل الأمر مباشرة لبرنامج MT5 على الكمبيوتر، والوضع الافتراضي حساب ديمو |

**تطبيق الجوال ما يقدر Claude يتصل فيه.** لكن تقدر:
- ترسل **صورة** للشارت أو الأسعار أو الصفقات، وClaude يقرأها.
- تعتمد على الأسعار المجانية اللي تجيبها المهارات تلقائياً، وهي متأخرة شوي.
- تعطيه أسعار تطبيقك، مثل: `TADAWAL_PRICES="EURUSD=1.03929,USDJPY=156.398"`.

## التثبيت

يحتاج Python 3.8 أو أحدث، بدون أي مكتبات إضافية.

### Claude Code كـ plugin
```
/plugin marketplace add eyad21aql/Tadawal
/plugin install tadawal@tadawal
```

### نسخ يدوي
```bash
git clone https://github.com/eyad21aql/Tadawal.git
cp -r Tadawal/skills/* ~/.claude/skills/
```
لازم تنسخ مجلد `_lib` مع المهارات، لأن فيه المكتبة المشتركة.

### موقع أو تطبيق Claude
```bash
python tools/build_zips.py      # -> dist/<skill>.zip
```
بعدها: Settings ← Capabilities ← فعّل Code execution ← Skills ← Upload،
وارفع ملفات الـ ZIP الـ 15 واحد واحد.

## الإعداد لأول مرة

1. انسخ `config.example.json` إلى `trader/config.json` في مجلد مشروعك.
2. عدّل فيه: رصيد حسابك (`account_balance`)، وعملة الحساب (`currency`)، ونسبة
   المخاطرة لكل صفقة (`risk_per_trade_pct`)، والمنطقة الزمنية (`timezone`، الافتراضي `Asia/Riyadh`).
3. إذا الوسيط يضيف حروف لأسماء الأزواج (مثل `EURUSDm` أو `EURUSD.pro`)، حطها في `symbol_suffix`.

## ربط MT5 على كمبيوتر Windows (اختياري)

1. ثبّت MT5 للكمبيوتر وسجّل دخول بنفس حسابك (ابدأ بالديمو).
2. نفّذ `pip install MetaTrader5`.
3. في MT5: من Tools ← Options ← Expert Advisors فعّل التداول الآلي، واضغط زر **Algo Trading**.
4. في الإعدادات غيّر `"mode": "mt5"`.
5. تأكد من الربط بالأمر `python skills/order-executor/order.py account`.

الحسابات **الحقيقية مرفوضة** إلا إذا غيّرت `"allow_live": true` بنفسك.

## طريقة العمل

```
trading-plan init          (مرة وحدة: قواعدك)
trading-plan today + economic-analyst calendar        (قبل الجلسة: أقدر أتداول؟ وش الأخبار؟)
cot-tracker / economic-analyst bias / currency-strength   (أي زوج وأي اتجاه)
market-structure / chart-scanner / entry-timer  ->  exit-planner
   ->  risk-manager size --setup NAME --write  ->  risk-manager check  ->  trading-plan check
   ->  order-executor tickets  ->  موافقتك  ->  place
price-alerts / exit-planner review           (المتابعة)
trade-coach review --days 7 / budget-manager report   (المراجعة الأسبوعية)
time-machine                                 (اختبار أي استراتيجية قبل المال الحقيقي)
```

## بدون تبييت (بدون سواب)

إذا فعّلت `"no_overnight": true` في الإعدادات، أو أنشأت الخطة بخيار `--no-overnight`:
- ما فيه صفقات جديدة بعد 16:00 بتوقيت نيويورك (12 بالليل بتوقيت الرياض في الشتاء).
- كل الصفقات لازم تتسكر قبل 16:45 بتوقيت نيويورك (12:45 بالليل)، يعني قبل التبييت الساعة 17:00 نيويورك (1 بالليل).
- هذي قاعدة إجبارية، ما تقدر تتجاوزها حتى لو كتبت سبب.
- التنبيهات تذكرك قبل الإغلاق بـ 30 دقيقة وبـ 10 دقايق، وأمر `order.py flat` يعرض لك الصفقات المفتوحة ويسكرها كلها.
- المدرب يعتبر أي صفقة عدّت وقت التبييت مخالفة.
- في الصيف (لما تتغير ساعة أمريكا) تصير المواعيد قبلها بساعة، والمهارات تحسبها تلقائياً.

## الحماية

- ما ينفَّذ أي أمر بدون ستوب، ولا بدون موافقة من مدير المخاطر عمرها أقل من ساعة،
  ولا بدون كلمة "نعم" صريحة منك. وأي تعديل على الأمر يلغي الموافقة.
- إذا عندك خطة تداول مفعّلة، الصفقة لازم تكون ضمن الخطة. ولو حبيت تتجاوزها لازم تكتب السبب،
  وتنسجل عليك كمخالفة يراجعها معك المدرب.
- حد للخسارة اليومية (اليوم في الفوركس يبدأ الساعة 17:00 بتوقيت نيويورك)، وحد للرافعة،
  وحد لعدد الصفقات المفتوحة، وتنبيه إذا عندك أكثر من صفقة على نفس العملة بنفس الاتجاه.
- في وضع `mt5`: يرفض الإرسال إذا كان السبريد أكبر من الحد اللي حددته.
- الستوب يتحرك لصالحك فقط، ما يتوسّع.
- كل تنفيذ ينسجل مع نص موافقتك في `trader/executions.json`.

## حدود يجب معرفتها

- أسعار Yahoo المجانية متأخرة وبدون أحجام تداول. أسعار MT5 حية.
- التقويم الاقتصادي المجاني ما يعطي أحياناً الرقم الفعلي بعد صدوره، فـ Claude يبحث عنه ويسجله.
- تقرير COT يصدر كل أسبوع ويوصلك متأخر 3 أيام، فهو يعطيك ميل عام مو توقيت دخول.
- النتائج السابقة لا تضمن المستقبل، والفوركس فيه رافعة عالية. **هذا ليس نصيحة مالية.**
